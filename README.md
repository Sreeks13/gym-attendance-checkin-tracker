# Gym Attendance Check-In Tracker

A Swift capstone project that validates raw gym check-in records, handles invalid input with errors, summarizes valid attendance, and reports flagged records.

## Features

- Check-in data modeling with structs
- Input validation with throwing functions
- Custom error handling
- do-catch validation loop
- reduce for attendance summaries
- Int extension for duration formatting
- Flagged-record reporting

## How to Run

Compile with Swift:

    swiftc AttendanceModels.swift main.swift -o GymAttendance.exe

Run with:

    .\GymAttendance.exe
